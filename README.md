# flat — плоские колонки для Agents Hub

![](icon.png)

Плагин страницы хаба: колонки (список сессий, лента, панель справа — например «Треды») идут от верхнего до нижнего
края окна, с прямыми углами и без зазоров; между колонками вместо полосы фона — тонкая линия цвета рамок темы.
Внутри тоже прямые углы (поле ввода, кнопки, метки, счётчики) и нет рамок, которые только обводят; круглыми остаются
точки статуса и аватар.
Работает в любой теме.

Поставить: «Настройки» → «Плагины» → «Найти» → flat, или хабу: «поставь плагин flagman/hub-plugin-flat».
Выключить — там же, в «Плагинах».

Только CSS (`flat.css`), без кода, который что-то читает или отправляет.
